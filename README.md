# Vijay Security Systems Pvt. Ltd. (VIJAY SECURITY)

High-fidelity, responsive multi-page website prototype built in **Next.js (App Router)** with **Tailwind CSS**, **Lucide Icons**, and Google Fonts (**Barlow Semi Condensed** + **Inter**), reproducing the 12 design screens from the official design system specification.

---

## 🎨 Design System

| Element | Specification |
|---|---|
| **Navy/Near-Black** | `#0A0F1A` (Hero, footer, dark panels, global dark sections) |
| **Secondary Dark** | `#111827` / `#0C1322` |
| **Brand Red** | `#E5322D` (CTAs, accents, active nav, icons, timeline dots) |
| **White** | `#FFFFFF` (Content sections, cards) |
| **Light Grey** | `#F3F5F8` (Cards, background strips) |
| **Border** | `#E3E7EE` (1px clean border) |
| **Text (Dark)** | `#0F172A` (Headings on light background) |
| **Text (Muted)** | `#64748B` (Body text on light background) |
| **Typography - Headings** | **Barlow Semi Condensed** (Bold, uppercase, tight line-height) |
| **Typography - Body/UI** | **Inter** |

## 📁 Component Architecture

```
src/
├── app/
│   ├── layout.tsx             # Root layout with fonts, sticky Navbar, and dark Footer

│   ├── page.tsx               # Screen 1: Home Page
│   ├── about/page.tsx         # Screen 2: About Page
│   ├── solutions/page.tsx     # Screen 3: Solutions Page
│   ├── industries/page.tsx    # Screen 4: Industries Page
│   ├── projects/page.tsx      # Screen 5: Projects Page
│   ├── services/page.tsx      # Screen 6: Services / AMC Page
│   ├── amc/page.tsx           # Alias route for Services / AMC
│   ├── certifications/page.tsx# Screen 7: Certifications & Compliance Page
│   ├── clients/page.tsx       # Screen 8: Clients Page
│   ├── global-presence/page.tsx# Screen 9: Global Presence Page
│   └── contact/page.tsx       # Screen 10: Contact Page
├── components/
│   ├── Navbar.tsx             # Sticky dark navbar with red shield logo, blur, dropdown
│   ├── Footer.tsx             # Dark global footer with brand wordmark and nav links
│   ├── Hero.tsx               # Reusable inner page dark hero band with gradient
│   ├── HomeHero.tsx           # Home hero with glass tower and surveillance camera
│   ├── StatCard.tsx           # Dark metric stat card with animated count-up
│   ├── SolutionCard.tsx       # 3x3 light card with red icon and modal inspector
│   ├── IndustryTile.tsx       # Sector tile with hover zoom and dark label bar
│   ├── ProjectCard.tsx        # Project card with tags, image, and case study modal
│   ├── CertificateCard.tsx    # Document card with credential modal lightbox
│   ├── LogoCard.tsx           # White logo card with authentic brand emblem
│   ├── ContactForm.tsx        # Validated contact form and Mumbai office map card
│   ├── InfrastructureDiagram.tsx # VSSL central architecture branching diagram
│   ├── TechnologyShowcase.tsx # 6 icon tiles + Live surveillance slider panel
│   ├── FeaturedProjectShowcase.tsx # Telenor India featured case study
│   └── CtaBand.tsx            # Global dark CTA section
└── data/
    └── siteData.ts            # Centralized typed data models, specs, and imagery
```

## 💻 How to Run Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) (or `http://localhost:3001` if 3000 is occupied) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```
All routes are pre-rendered into static pages for optimal performance and SEO.
